🔧 Firebase

Вставь конфигурацию своего Firebase Web App. Настройки сохраняются только в браузере этого устройства.

В Firebase Authentication включи Email/Password; в Firestore опубликуй правила из файла firestore.rules. Для двух устройств нужна одна и та же конфигурация проекта.
