🔧 Подключение Firebase

Создай проект Firebase и вставь конфигурацию веб-приложения. Она не является секретным ключом; доступ защищается правилами Firestore.

Как настроить Firebase

1. Создай проект на console.firebase.google.com.
2. Добавь Web App (значок </>) и скопируй объект firebaseConfig.
3. В Authentication → Sign-in method включи Email/Password.
4. В Firestore Database создай базу.
5. В Rules установи правила из файла firestore.rules, затем Publish.
6. Открой игру через HTTPS (например, Firebase Hosting), если браузер блокирует локальные модули.
